# ParentRight Korea

Information guide for mothers abroad whose child's father is Korean: paternity (acknowledgment) cases in Korean family courts, child support, Korean nationality, and where to get help in Korea.

- No personal information about any individual is published or collected.
- Edit `build.py`, then run `python3 build.py` and copy `site/` contents to the repo root.

- Project notes, legal research and open tasks: `docs/project-notes.md`
- Brand assets: `assets/` (logo and draft options)
- Working with Claude Code: see `CLAUDE.md`
